## Engineering Background

**Backend Systems — Java (Primary, Expert)**

Java is my core stack with 6+ years of production experience. This spans legacy JBoss-hosted Java EE systems, Spring Framework version migration projects, Spring Boot microservice architectures, and MyBatis ORM in high-volume transactional financial environments. Primary clients have been large Japanese financial institutions (securities, asset management, insurance) and Korean enterprise IT.

**Frontend Development — ReactJS & Angular (Advanced)**

Frontend is a genuine production skill, not secondary. ReactJS (5 years, Advanced) and Angular/AngularJS (4+ years, Advanced) are delivery stacks across multiple enterprise projects — not just integration touchpoints. TypeScript across both ecosystems. This spans SPA development, component architecture, and API contract design between frontend and Spring Boot backends.

**Database Engineering — PostgreSQL & Oracle (Expert/Advanced)**

PostgreSQL is the primary database with 6+ years at Expert level. Oracle PL/SQL for 3+ years across financial systems — asset management, securities monitoring, insurance contract processing. Hands-on work includes EXPLAIN PLAN and AWR report analysis, slow query log investigation, composite and partition index design, complex query rewriting, table partitioning, materialized view optimization, PL/SQL package development, and large-scale data purge operations.

**Measured result:** Reduced a critical 5-table join query over 3 million records from **30 minutes → 5 minutes** through index restructuring and query rewrite.

**System Migration & Modernization**

Multiple migration projects delivered across different migration types:
- **Framework migration:** Spring legacy → Spring Boot. XML-based configuration → Java-based config, dependency upgrade and conflict resolution, code refactoring, test coverage post-migration, UAT support with client.
- **Security platform consolidation:** Multiple legacy security systems consolidated into one unified security platform — with performance tuning on both query and API layers.
- **Frontend migration:** Flex/JSP → Angular SPA across financial system frontends.
- **Analytics code migration:** SAS analytics logic → PostgreSQL for Singapore government education system.

Practical experience with phased cutover and parallel-run patterns in production financial systems with zero-downtime delivery constraints.

**Cloud — AWS (Applied)**

AWS used in production CI/CD pipelines and cloud-migration projects: CodeCommit, CodePipeline, CodeDeploy, Secrets Manager, Elastic Load Balancer. Certified AWS Cloud Architect and Data Engineering with AWS. AWS knowledge is applied and certified — used primarily in financial system delivery pipelines and insurance contract system migration to cloud.

**DevOps & Infrastructure — K8s, GitHub Actions, AWS EC2**

Hands-on infrastructure setup outside of enterprise delivery: containerized application deployment using Docker and Kubernetes, automated CI/CD pipeline with GitHub Actions (build → Docker image → push → deploy), targeting AWS EC2. End-to-end pipeline design from code push to production deployment.

**Low-Code Enterprise Platforms**

Certified Mendix Advanced Developer and Rapid Developer. Certified Pega System Architect (CSA). Production delivery on Mendix-based enterprise applications including a Japanese market B2B webapp. Experience evaluating the low-code vs. custom-build trade-off in enterprise contexts where the decision has significant long-term cost implications.
