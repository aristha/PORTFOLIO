## Current Narrative

The portfolio is organized around four engineering themes:

1. **AI-assisted engineering** — bounded agent authority, deterministic evidence, independent review, human approval.
2. **Architecture & modernization** — incremental migration, modular design, and trade-off driven decisions.
3. **Performance & reliability** — evidence-based optimization across data and application layers.
4. **Technical leadership** — decision-making, review gates, delivery coordination, and engineering judgment.
